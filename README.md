# 📝 人工智能训练师刷题系统

为备考「人工智能训练师」国家职业资格考试开发的刷题Web应用，收录300道选择题，支持即时答题反馈、随机出题、章节分类练习、错题统计。

## 🔗 在线体验

https://qiangzhao2453.github.io/rgzn-sttk/

## 🎯 项目背景

2026年备考人工智能训练师（三级/高级工）证书时，发现网上找不到针对该考试的在线刷题工具——题库资源分散、多为PDF格式、无法即时反馈、没有错题追踪。于是自己动手开发了一套刷题系统，边用边迭代。

最终成绩：**通过考试，取得人工智能训练师三级/高级工认证（2026年6月）** 。

## ✨ 核心功能

- **即时答题反馈**：选择后立即显示对错，给出正确答案和解析
- **随机出题模式**：打乱题目顺序，避免死记硬背位置
- **章节分类练习**：按知识模块分类，可针对性刷题
- **错题统计**：自动记录答错的题目，方便集中复习
- **进度追踪**：显示答题进度和正确率
- **纯前端运行**：无需后端服务器，打开即用

## 📊 题库数据

- **总题量**：300道选择题
- **覆盖范围**：人工智能基础知识、机器学习基础、数据处理、模型训练、智能体应用、伦理规范等
- **题目来源**：官方考试大纲+权威教材+历年真题整理

## 🔄 迭代历程

- **v1.0**：基础版——固定题目列表+对错判断
- **v2.0**：增加随机模式+章节分类+答题进度
- **v3.0**：增加错题统计+解析显示+UI优化，达到可用状态

## 🛠️ 技术栈

- **前端**：HTML + CSS + JavaScript
- **数据**：内联JSON格式题库
- **部署**：GitHub Pages
- **开发方式**：自主开发 + AI辅助调试

## 🚀 本地使用

1. Clone本仓库
2. 浏览器打开 index.html
3. 开始刷题，无需联网
